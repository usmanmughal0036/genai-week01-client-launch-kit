# AI Client Launch Kit — Week 1

## Project overview
This demonstration project combines AI-assisted marketing content, a social media poster, a short voiceover script, and a prompt-driven customer support assistant for a fictional local business.

## Fictional client brief
- **Business:** Naya Skills Academy
- **Service:** Weekend Excel Workshop
- **Format:** In person
- **Location:** Rawalpindi
- **Duration:** 90 minutes
- **Fee:** PKR 1,200
- **Audience:** Fresh graduates
- **Booking:** Direct message (DM)

## Tools
- ChatGPT or Gemini — drafting and refining copy
- Canva or a similar design tool — optional poster editing
- Google AI Studio — running the prompt-based assistant prototype
- GitHub — storing and documenting the project

## Deliverables
- `launch_copy.txt` — Instagram captions and WhatsApp message
- `poster.png` — social media poster, 1080 × 1350 px
- `faqs.txt` — four customer FAQs
- `voiceover_script.txt` — approximately 15-second narration
- `assistant_prompt.txt` — assistant system instructions
- `assistant_test_results.txt` — test cases and result record
- `START_HERE.txt` — setup and submission guidance

## My role
Prompt design, marketing copy drafting, factual verification against the supplied brief, visual layout, support-assistant configuration, and response testing.

## Important scope and accuracy note
The business and workshop details are fictional and are used only for this demonstration. The assistant is a prompt-based prototype, not a trained model or a deployed retrieval-augmented system. It does not automatically integrate with WhatsApp or process bookings. Unknown details such as the exact date, certificates, discounts, refunds, and seat availability must be confirmed rather than invented.

## Before publishing
1. Run the assistant tests in Google AI Studio and replace sample responses with actual outputs.
2. Check the poster text and spelling at full size.
3. Keep passwords, API keys, private client records, and other confidential information out of the public repository.
4. Upload the final files to the repository named `genai-week01-client-launch-kit`.
